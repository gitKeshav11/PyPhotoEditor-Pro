# 🎨 PyPhotoEditor-Pro -- Advanced Python Image Processing Toolkit

PyPhotoEditor-Pro is a powerful Python-based photo editing and image
processing project designed to demonstrate real-world application
development, image transformation, and efficient data handling using
Python.
This project highlights practical implementation of image processing
techniques such as transformation, PNG handling, and automated
input-output processing. It is designed as a **portfolio-ready project**
for developers and students who want to showcase strong Python and
problem‑solving skills.

This project processes images through structured modules:

-   Reads images from input folder\

-   Converts/handles PNG formats\
-   Saves edited images to output folder\

## 💻 Installation & Setup

### 1️⃣ Clone Repository

``` bash
git clone https://github.com/gitKeshav11/PyPhotoEditor-Pro.git
```

### 2️⃣ Open Project Folder

``` bash
cd PyPhotoEditor-Pro
```

### 3️⃣ Install Dependencies

``` bash
pip install -r requirements.txt
```

### 4️⃣ Run Project

``` bash
python image.py
```

## 📄 File Description

**input/**\
Contains all raw images that will be processed.

**output/**\
Stores final processed and transformed images.

**image.py**\
Main module handling image reading, editing, and processing workflow.

**png.py**\
Handles PNG file operations and conversions.

**transform.py**\
Contains transformation functions like resize, rotate, filters, etc.

**transform_empty.py**\
Starter template to practice or extend transformation logic.

**requirements.txt**\
All required Python libraries for project execution.
